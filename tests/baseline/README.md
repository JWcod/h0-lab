## 資料切分

- **holdout**:判斷日 ≥ 2024-10-01(最近約 2 年的判斷;12 個月評等只有 2024-10 ~ 2025-09 這 12 個月的判斷有答案)。
- **開發集**:判斷日 + 預測期 ≤ 2024-10-01(結果視窗跨進 holdout 的判斷要剔除,避免間接偷看)。
- 每次看 holdout 都要記在 `docs/holdout 評估日誌.md`。

## 讀這份基準要知道的事

1. **12 個月命中率的有效樣本很小**:每月判斷一次、看之後 12 個月,相鄰月份的答案幾乎重疊。5 年多只有約 4.7 個獨立期間;
   一般二項分布的 CI(例如台股 56.2% ~ 61.3%)窄得不合理,要看區塊 bootstrap 的區間。
2. **網站上「t ≥ 2 算顯著」高估了**:例如台股長期綜合分 12 個月 IC 的天真 t = 3.2,但考慮重疊後的 CI 包含 0。
3. **v1.1 的兩條規則是看過 2021–2026 全期結果才加的**,所以 holdout 期間在 v1.1 設計時已經被看過(記為汙染,見評估日誌)。
4. **最近一年變差**:台股 12 個月 holdout 45.5%、美股 44.7%(都只有約 1 個獨立期間,只能當方向參考)。
5. **評等不單調**:台股「持有」跑贏比例 57%,高於「強力買進」54%;模型的資訊主要在「避開減碼 / 賣出」(跑贏比例 33%)。
6. **Brier 無法計算**:v1.1 沒有輸出機率;v2 要加上校準過的機率,才能和「永遠猜 50%」的 0.25 比較。
