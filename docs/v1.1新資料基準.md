## 1. 方法

| 項目 | v1.1 凍結基準 | 這次(PIT 新資料) |
|---|---|---|
| 模型 | v1.1 `judge_at` | **同一個函式,沒有改** |
| 股價 | yfinance 10 年,Close 已被往回調整「之後才發生」的配股 / 分割 | PITStore 原始價格,只套用 d 以前的分割 / 配股 / 減資(`price_asof` → `view.prices('split')`,yfinance 欄名);Yahoo 2013 起長歷史(`history_since`) |
| 下市股 | 沒有 | 證交所 STOCK_DAY 原始日價格 + FinMind 配股 / 現金股利(`build_tw.twse_daily_hist`) |
| 台股財報 | 季末 + 45 天(Q4 + 90 天)、FinMind 本益比 | `tw_fdat_asof`:法定期限 + 1 交易日、每股數字換到 d 的股數基準、本益比 = PIT 價格 ÷ 當時已公布的 TTM EPS |
| 美股財報 | 年度結束 + 75 天、今天的 SEC 數字 | `annual_table_asof`:每個申報版本、申報日 + 1 交易日;`_avail` = 這個年度第一次公布的日期(同一份申報第一次帶出好幾個年度時,較舊的年度錯開幾奈秒,不改變「≤ d」的結果) |
| 大盤 / 總經 | ^TWII、^GSPC、^VIX、^TNX、TWD=X(10 年) | 同樣的序列,Yahoo 2013 起長歷史,截到 d |
| 股票池 | 網站 TW_LARGE 40 / US_LARGE 40 | 台股每月 `universe_pit.tw_universe(d, 50)`(PIT,含之後下市的公司);對照組 TW_LARGE 40;美股 US_LARGE 40 |
| 期間 | 2021-01 起 | 台股 2016-01 起、美股 2015-01 起,到 2026-09(資料最後一個完整月) |
| 判斷日 | 每月最後一個營業日,對齊大盤交易日 | 同左 |
| 評估 | `evaluate` 新模式(附錄 A,`docs/閘門校準.md`) | 同一個新模式:t+1 成交、store 的 'total' 含息報酬、超額 = 個股 − 同日股票池中位數、實際成本;大盤改用**含息指數**(證交所發行量加權股價報酬指數 / ^SP500TR) |

- 同一個(股票, 判斷日)的判斷只和這兩個有關,兩個台股股票池共用判斷結果(只算一次:共 13,743 個不重複判斷)。
- 下市股的含息報酬指數:最後一筆以後用最後價格持平延伸到日曆結束(= 下市報酬 0%;A3 查到的下市都是併購 / 股份轉換)。
  不延伸的話,持有期間跨過下市的判斷會因為沒有出場價被排除,等於另一種存活者偏誤。
- 產業別(`resolver.tw_lookup`、Yahoo `industryKey`)沿用 v1.1:是**今天**的分類,不是 PIT(只影響景氣循環偵測與金融業判斷);竄改測試抓不到這個。
- 實驗登記簿:每次 `evaluate` 自動登記,`family = "baseline"`(3 個股票池 × 全期與 2 個子期間 = 9 筆)。

## 5. 和凍結基準(tests/baseline、`docs/閘門校準.md` 附錄 A)的差異來源

一次換一件事(開發集、同一個新模式評估,主要指標月 IC:長期 12 個月 / 長期 6 個月 / 短期 1 個月):

| 步驟 | 改了什麼 | 台股 | 美股 |
|---|---|---|---|
| A | v1.1 凍結基準(網站 40、2021-01 起、Yahoo 價格、價格大盤) | −0.002 / +0.069 / +0.045 | −0.035 / −0.051 / −0.004 |
| B | **資料修正**:換成 PIT 資料,股票池與期間不變(網站 40、2021+) | −0.005 / +0.064 / +0.049 | −0.040 / −0.047 / +0.006 |
| C | **期間**:再延長到 2016-01(美股 2015-01)起 | +0.031 / +0.049 / +0.048 | +0.042 / +0.026 / +0.023 |
| D | **股票池**:台股再換成 PIT 前 50 | +0.020 / +0.030 / −0.001 | (美股沒有 PIT 股票池) |

1. **資料修正(A → B)影響小**:IC 變動都在 0.01 以內。逐筆比較(2021-01 ~ 2024-09 重疊的判斷):台股 1,800 筆評等相同 85.2%、短期訊號相同 98.6%,
   價格差 > 0.5% 的有 25.4%(v1.1 的 Yahoo Close 被往回調整了之後才發生的配股);美股 1,594 筆評等相同 74.4%,公平價中位數比 0.951,
   PIT 多 45 筆、少 11 筆(年報可用日改成實際申報日)。
2. **期間(B → C)影響最大**:12 個月期滿世代月份從 21 個變成 81 個(美股 93 個);2016-2020 的 IC 比 2021+ 高,美股的 12 個月期因此從負轉正。
3. **股票池(C → D)讓台股變差**:PIT 前 50 的短期 1 個月 IC 從 +0.048 變成約 0、長期 6 個月從 +0.049 變成 +0.030。
   網站 40 是用今天的眼光挑的公司,模型在那群公司上的表現不能代表當時真的會遇到的股票池。
4. **成本與 t+1**:A ~ D 全部用同一個新模式(t+1 成交、台股買 0.1425% / 賣 0.4425%、美股每邊 0.05%),所以這張表裡沒有這一項的差異;
   舊模式 → 新模式的差異見 `docs/閘門校準.md` 附錄 B(t+1 本身影響很小)。投組「全部等權 − 大盤」另外受大盤從價格指數換成含息指數影響(含息指數每年比價格指數高約一個股利殖利率:台股約 3 ~ 4、美股約 1.5 ~ 2 個百分點)。

## 6. 重跑方式(維護者在凍結資料上用同一個指令)

```
INVEST_LAB_OFFLINE=1 INVEST_LAB_DATA_DIR=<凍結資料夾> INVEST_LAB_OUT_DIR=<輸出資料夾> INVEST_LAB_AGENT=<名稱> \
  .venv/bin/python -m lab.research.backtest_pit all --workers 8
```

- 分步:`build`(建 store,約 46 秒)、`judge`(13,743 個判斷,8 個 worker 約 151 秒)、`evaluate`(只算開發集,約 15 秒);這次全部約 213 秒(10 核心)。
- 凍結資料夾需要的快取 namespace:`px_since`、`twse_stock_month`、`twse_tr`、`twse_daily_all`(PIT 股票池)、`finmind`、`sec*`、`yahoo`(分割史、產業別)。
  台股名單 = 2016-01 起曾入選 PIT 前 50 的代號 ∪ `data/research/tw_pit50_union.txt`(有的話)∪ 3167 ∪ TW_LARGE。
- 輸出的 `rows_<股票池>.csv` 含 holdout 期間的判斷(只有評等,沒有結果),給 `scripts/holdout.py` 用。
