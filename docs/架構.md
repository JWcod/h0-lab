## 1. 執行模式與環境變數(必須在 import lab 之前設定)

| 變數 | 用途 | 主 checkout 預設 | 開發工作階段 |
|---|---|---|---|
| `INVEST_LAB_OFFLINE=1` | 離線:socket / requests / curl_cffi / yfinance 全封鎖;快取永不過期,找不到記 cache miss | 關 | **一律開**(Fetcher 除外) |
| `INVEST_LAB_DATA_DIR` | 讀資料(快取、凍結版本) | `data/` | 唯讀凍結版本,例如 `data/frozen/v1.1_2026-10-15` |
| `INVEST_LAB_OUT_DIR` | 可寫的輸出(回測結果、掃描、非正式快照) | `= DATA_DIR` | 自己的資料夾,例如 `.agent_out/<agent>` |
| `INVEST_LAB_PRIVATE_DIR` | 觀察清單、筆記、模擬帳戶 | `private/` | **假資料**,例如 `.agent_out/<agent>/private_fake`;**不得開啟真實 private/** |
| `INVEST_LAB_AS_OF` | 模型眼中的今天 | 今天 | 離線時自動讀凍結資料夾的 `freeze_date.txt` |
| `INVEST_LAB_RECORD=0` | 不寫前瞻紀錄 | 開(主 checkout、連網才寫) | 自動關(worktree 或離線) |
| `INVEST_LAB_PARAMS` | 模型參數檔(預設 `lab/model_params.json`);重現舊模型時指到凍結資料夾的 `model_params.json`(v2 回歸測試這樣用)。v2 的新規則一律用參數鍵開關,舊參數沒有該鍵 = 舊行為 | `lab/model_params.json` | 不要改(除非重現基準) |
| `INVEST_LAB_AGENT` | 寫進實驗登記簿的呼叫者名稱 | `user` | 例如 `C1` |
| `INVEST_LAB_REGISTRY`、`INVEST_LAB_BUDGET_FILE` | 實驗登記簿、FinMind 額度檔 | 主資料夾 `data/` 底下 | 不要改(所有 worktree 共用) |
| `INVEST_LAB_HOST`、`INVEST_LAB_PORT` | 伺服器位址與埠;HOST 只允許 `127.0.0.1`、`localhost`、`::1`,其他值啟動即拒絕(Red-team L4,階段 5) | `127.0.0.1:8765` | 測試站用別的埠,絕不用 8765 |

| `INVEST_LAB_ENV_FILE` | 使用者 `.env` 的位置(App 由 launcher 指到使用者資料夾) | 專案根目錄 `.env` | 不要改 |
| `INVEST_LAB_UPDATE_CHECK=0` | 完全不查新版本(`lab/updater.py`) | 開(每天最多一次) | 離線模式本來就不查 |

打包的 App(`packaging/`)由 launcher 在 import lab 之前設好上面的路徑,全部放在 `~/Library/Application Support/H0 Lab/`。

前瞻紀錄(`data/snapshots/`、`private/paper.json`)是唯一真正乾淨的樣本外資料:只有主 checkout、連網、`INVEST_LAB_RECORD` 沒關時才寫;快照附 `git_sha` 與 `forward_record`。

## 2. 抓資料與寫程式分開

- **Fetcher**(維護者,或明確指派的 A 線單元):唯一可以連網、寫原始資料、建立新資料版本的角色,依序執行,遵守各來源條款、限速、robots;快取、退避重試、失敗時回傳舊資料並記 `cache.stale_events`。
- 其他所有開發工作階段(Builder、Verifier、Red-team、稽核)**離線**,只讀凍結資料。
- 資料版本:`data/frozen/<vintage>/`(`cache/`、`pit.sqlite`、`freeze_date.txt`、`model_params.json`),建好後 `chmod -R a-w`。

### 3.1 評估框架 `lab/research/evaluate.py`(C1 實作,介面如下)

- `forward_returns(view_or_panel, dates, horizon, lag=1, kind='total')`:判斷日 d 收盤決策,**d 的下一個交易日**成交;報酬用含息報酬。
- 主要指標(Q3):
  - 長期評等:重疊世代月 IC(每月持有過去 12 個判斷世代各 1/12)+ Newey–West 標準誤(lag = 預測期月數)。
  - 短期訊號:1 個月 IC + Newey–West。
  - 命中率一律附覆蓋率;比較時用「固定覆蓋率」版本(分數前 / 後 20%,兩邊名額都是 floor(0.2n);在當天所有有判斷的列排名、平手用固定 seed 打散,之後才丟沒有報酬的列,Red-team M4)。平手(超額 = 0)不算對也不算錯。沒有評等的列不得當成中性。
  - 三分位價差另報截尾版(橫斷面報酬截尾 1% / 99%,`tercile_spread_monthly_winsor`,只是敏感度;Red-team L1)。投組報酬是實際淨值路徑,不截尾。
  - 目前版本 `EVAL_VERSION = evaluate-v2.1`(階段 5);版本進設定 hash,換版本 = 新設定。
- 區塊 bootstrap 只在獨立期數 ≥ 8 時使用;每個指標用自己的名稱衍生固定 seed(`seed = hash(指標名)`)。
- `paired_gate(base_rows, new_rows, spec)`:同一資料版本、同一股票池,只比雙方都有判斷的「日期 × 股票」交集,共用同一組重抽索引;覆蓋率差異另報。報告附差異序列的 AR(1) 係數,φ̂ > 0.5 時警告(Red-team M5)。
- `holdout_paired(...)` / `holdout_pair_verdict(...)`:看過開發集才登記、只能用 holdout 檢驗的假設(`prereg.HOLDOUT_ONLY`,例 P3-H01),和最終設定在**同一次** holdout 裡配對比較;`scripts/holdout.py --compare 族:鍵=檔`,配對檔進設定 hash。判準與股票池角色寫在 `HOLDOUT_PAIR_M`、`HOLDOUT_PAIR_POOLS`。
- 每次呼叫自動 `registry.log(...)`。
- **預設只算開發集**;`split='holdout'` 只能由 `scripts/holdout.py` 觸發(會自動寫 holdout 日誌、在 worktree 或離線 agent 模式下拒絕執行)。
- 在凍結資料上用 v1.1 的定義必須算出和 `tests/baseline/metrics_v1.1.json` 一樣的數字(保留舊模式)。

### 3.2 合併閘門(不對稱)

- 增加特徵或參數:必須證明更好(主要指標差異的 95% 區間不含 0,依 `registry.n_trials()` 做 Holm 校正),且台股 / 美股方向一致、兩個子期間方向一致。
- 簡化或修錯:只要求不更差(差異下界 ≥ −門檻,門檻由閘門校準決定)。
- 次要指標固定清單(Holm 校正):換手率、成本後投組差、最大回撤(含相對大盤)、評等分組單調性。
- CI 內的改善一律標「沒有證實有效」。資料改動只用正確性判斷,不看模型指標;資料改動與模型改動不同 commit。

## 5. 測試分層

- `pytest -q`:快速測試(預設排除 slow)。
- `pytest -q -m slow`:需要凍結資料的回歸測試(v1.1 基準逐位元重現)。
- 每條特徵管線、模型擬合、門檻選擇:竄改測試。
